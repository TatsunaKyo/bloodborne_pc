# Security reports

I maintain The Crowned Workshop as an experimental native port. Please keep the version you tested, the affected feature and the reproduction details together when reporting a security problem.

Use **Security → Report a vulnerability** if private reporting is available on this repository. If it is not enabled, open a minimal issue asking me to arrange a private channel; leave the vulnerability details out of that public issue. I do not have a dedicated security inbox published for this fork yet.

Do not post account passwords, tokens, save files, decrypted game files or raw crash dumps publicly. A dump can contain private memory and paths. Review logs and archives before attaching them.

The latest stable release is the starting point for fixes. Older releases stay available for comparisons, but I cannot promise separate security updates for every historical revision. The updater stays on this fork's Windows stable channel; version and package integrity checks are described in [the release guide](docs/releasing.md).
