# Bloodborne Windows v1.6 — TatsunaKyo revision 7

This revision fixes the cheat player lookup that made the new options ineffective and could crash after a save loaded. The lookup now compares against the game's actual main player and safely skips player-only changes while loading. All the cheats are in the same section; startup patches are marked as needing a restart. Damage, incoming damage reduction, Echoes, movement, stamina and consumable hooks were tested with both native trampolines and the actual Windows-compiled object. Gameplay still needs checking on Windows.

FSR Frame Generation now accepts HDR10 as well as SDR. The generated frame is converted back to PQ without clipping highlights to SDR white. The real capture and AMD FI/OF passes passed the GPU fixture with zero Vulkan validation errors or warnings, including 500/1000/2000-nit highlights and switching back to SDR.

The package introduces an experimental NVIDIA DLSS FG/MFG backend using Streamline 2.14.1 and production DLSS-G 310.9.1. The launcher and in-game menu have the FG selector, 2x–6x multiplier choices and separate Reflex Off / On / On + Boost controls. The SDK checks the GPU's actual limits. Reflex can run with FG off, and NVIDIA FG enables low-latency Reflex automatically. The NVIDIA path accepts actual SDR/HDR10 output and waits for SDK ownership before reusing input buffers. It has been compiled and packaged, but activation, HDR display, quality and Alt-Tab have not been tested on a physical RTX in this environment.

The ordinary FPS cap still limits real game frames. A 75 FPS choice is therefore allowed to produce 150 with 2x FG. A separate **Limit total FPS with Frame Generation** checkbox enables an integer slider from 30 to 1000: 120 total at 2x derives a 60 real-frame ceiling. This cap is optional and does not raise the game's simulation rate. Background Pause / 30 / 60 continue to disable generation while unfocused; Keep running preserves it. The native pause/refocus fixture still completes 30 cycles with the window event thread active.

FG presets A/B, a separate HUDless/UI-alpha composition path, Dynamic MFG and AMD ML FG are not included. A/B needs actual UI recomposition inputs before it can be exposed as a working option. DLSS super-resolution presets E/F/J/K/M/L are unchanged. The game HUD can show interpolation artifacts, and the NVIDIA OSD readout is an application presentation-rate measurement rather than a measured total-FG output counter. See the [FG guide](../frame-generation.md) for the exact scope.

Both `Bloodborne.exe` and `bin/bb-probe.exe` are rebuilt. Extract the complete ZIP into a new folder and launch `Bloodborne.exe`; keep your existing saves, mods and configuration. FG, Reflex and the new total cap start off. The launcher payload, actual ImGui controls, persistence, FPS-cap behavior, cheat hooks and runtime DLL imports are verified. No game files are included and no gameplay FPS or latency improvement is claimed from headless tests.
